# Mockup changes for RigLedger 2.0.4

File: rigledger_android_mockup.html (dummy data, click-through). Source of truth: the Flutter code in rig-ledger and docs/v2.0.4-review.md.

- Version text is 2.0.4 (build 9) in the page title, sidebar, Settings About tile and About screen.
- Step Rates: new Settings tile "Step Rates" (trend icon) above "Ledger Types", opening a Step Rates screen (Rig dropdown with main bore rigs only, info box, "7 inch table" and "8 inch table" cards). Each card has "Step rate starts after" (ft), one row per 100 ft bracket with an X (disabled with one row), Add bracket (new row = last + growth), "After the last bracket, extra per ft grows by", and a live example line (feet = start + 100 x (rows + 1)). Reset to standard (confirm dialog) and Save (snack "Step rates saved. New bills use them"; invalid field: "Fill every rate with a number"). Tables live in STEPR per main bore rig (only Main Rig exists in the dataset); `stepCalc` mirrors `StepTable.calculate`.
- New bills (and a saved bill whose depth lines were edited, unless its step rate is manual) use the current tables. A saved bill opened without changing its depth lines keeps its stored step rate (`stepSig` check); the Auto button next to Step Rate recalculates with the current tables. Stored bill numbers, ledger cards and Portfolio never change when a table is edited.
- Portfolio agent view: new card "Feet and commission by type" after the Bills/Total and Received/Pending cards and before By month: Depth, PVC and MS pipe groups, header "Total N ft  |  amount", one chip per type with feet (types without feet left out) and a second line "Commission X" (sum of feet x line commission rate per type). The manual-commission note shows when any bill in the view is manual.
- Account Ledger entries have an optional rig (`rg`): "Rig (optional)" field below the notes/description and above Accounts in the entry form (opens a picker with No rig and the rigs); for a payment-linked entry the field is greyed with the helper "Set from the bill". Rows show the rig name with the factory-style icon under the date/time line. Dummy data: linked entries (bills 1039 and 1042) carry the bill's rig; Diesel for rig and Compressor service are Main Rig, Spare parts is Side Rig 1; transfers and the rest have none. Save, Save and add another, edit Save and Copy now really write to the in-page entry list and keep the chosen rig. Report dialogs note the trailing CSV "Rig" column and the PDF "Rig: NAME" line.
- Sidebar: Step Rates (default, edited with an extra bracket, reset dialog), agent view Feet and commission by type, Account Ledger "Home (rig names on rows)", entry form with the Rig dropdown open, edit entry with a rig, linked entry form (rig locked).

Not done: only one main bore rig exists, so the rig dropdown in Step Rates has one choice; there is no separate CSV or PDF preview screen for the Account Ledger (the Report dialogs carry the note instead); the rig icon is precision_manufacturing_outlined (as in the app code), not a factory glyph.
