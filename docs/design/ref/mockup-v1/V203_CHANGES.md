# Mockup changes for RigLedger 2.0.3

File: rigledger_android_mockup.html (dummy data, click-through). Source of truth: the Flutter code in rig-ledger and docs/v2.0.3-review.md.

- Version text is 2.0.3 (build 8) in the page title, sidebar, Settings About tile and About screen.
- Agent prices update existing bills. Saving the Edit agent dialog runs commRecalc() on the in-page dataset (mirror of CommissionRecalc.changedBills): bills with a hand-set commission (`man`, shown with the "manual" tag) are skipped; on the other bills of the agent a line takes the new price only when its commission rate equals the agent's OLD price for that line type (agent price per type, else the category default); a line with another rate keeps it; side bore bills use the agent's default depth rate; the bill commission becomes the sum of feet x line rate (paise). Ledger cards, summary strip, Portfolio and the agent view all read the changed values. Snack: "Agent updated" or "Agent updated. Commission changed on N bills" ("bill" when N is 1).
- Dummy data: bill 1044 has a hand-typed 8inch depth commission rate (11, agent price 12), so it keeps it when that price changes. Bill 1041 (Selvam) is the manual-commission bill. New bills 1034 (Selvam, Aug), 1035 (Murugan, Aug) and 1036 (Murugan, Sep) so Murugan and Selvam have bills in Aug, Sep and Oct. A stray array hole after bill 1043 was removed.
- Portfolio agent view: choosing an agent (pill sheet or tap on an agent row in the Agents section) replaces the profit card, metric grid, expenses card, Agents section and definitions with: gradient header (name, period "01 Aug 2026 to 31 Oct 2026" or "All time", Commission earned, "All agents" back button, tune icon opening the details sheet); profit card (green or red) with expected, "All agents, after expenses" and the expenses note; Bills / Total and Received / Pending cards; a "By month" table when the period spans months; one card per bill, newest first, with a commission strip ("Commission (manual)" without split for manual bills, "Depth X  PVC Y  MS Z" otherwise); tap opens the bill form; totals row. Empty case: "No bills for NAME in this period". Agent rows: tap opens the agent view, small info icon (title "Prices and details") opens the details sheet, chevron removed. Back button, "All agents" in the sheet, scope change and rig change return to the normal Overview. The agent profit is received - commission; expected is billed - less - commission; the overall line is received - expenses - commission of all agents in the period and scope.
- Sidebar: new Portfolio entries for the agent view (this month, 3 Mo with By month, 3 Mo with the manual bill, empty state) and the Edit agent dialog (also opened from the agent view). The old "Overview (agent filter)" entry is now the agent view.

Not done: the period end for "Month" and "3 Mo" is the end of the month (the app text may use today as the end); the hint text inside the Edit agent dialog is unchanged (the app dialog has none).
