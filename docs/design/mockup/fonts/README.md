# Vendored fonts

- `MaterialIconsRound-Regular.otf`: Material Icons, Rounded set. Source: github.com/google/material-design-icons (font/). License: Apache 2.0. Glyph names map one to one to Flutter `Icons.<name>_rounded`.
- The UI text uses the system stack `-apple-system, BlinkMacSystemFont, "SF Pro Text", Inter, system-ui, sans-serif`. No text font is vendored here. The Flutter build bundles Inter (see TOKENS.md).
