# RigLedger v2.0.1 review

Release 2.0.1+6. Flutter app only (Android). 11 bugs from the developer list, tasks T-H01 to T-H14 in `.claude/tasks/CURRENT.md`.

## Bugs and what changed

| # | Bug | Change |
|---|---|---|
| 1 | Ledger entries hard to see | Header trimmed, month/year arrows and Daily/Calendar toggle share one row, pinned totals are one slim strip that scrolls sideways |
| 2 | Depth, PVC, MS types fixed | Settings, Ledger Types: add any size in inches, rename (updates bills and agent prices), delete (blocked while in use). Optional 7 or 8 inch step table per depth type, none by default |
| 3 | Agent commission per type | Agent has a price per foot for each depth, PVC and MS type, with the three old rates as fallback; bills follow the agent price when agent or type changes |
| 4 | Agents tab | Removed from the phone tabs; Agents section in Portfolio (add, detail sheet, edit, delete, prices). `agents_screen.dart` kept for the frozen desktop shell |
| 5 | Other expenses | New side ledger category for both rig types (typeId 12), in Side Ledger, Add Entry, Portfolio expenses and profit, Stats, CSV and PDF |
| 6 | Commission not visible | Form shows Depth, PVC, MS and Total commission (manual tag), Calculation Preview has a commission block, bill card shows a commission strip |
| 7, 8 | Portfolio rig and scope | Rig pill opens the rig picker, This rig / All rigs is a clear two-option control |
| 9 | Account Ledger looks different | Same header pills, summary card, floating row cards and rupee format as the ledger pages |
| 10 | Stays on form after save | Filled Save returns, outlined Save and add another keeps the form |
| 11 | File storage, PDF save error | Save goes through the system file picker only (no permission, no second write), Share fallback on failure, UTF-8 output, MANAGE_EXTERNAL_STORAGE removed |

## Data

Schema 6. New: `ledgerTypes` (settings JSON, merged by `updatedAt`), `Agent.commissionRatesJson` (HiveField 10), `OtherExpenseEntry` box. Older backups restore with defaults; a snapshot from 2.0.1 is not readable by apps that only know schema 5 data for the new keys (they ignore them).

## Tested

102 automated tests pass (types, step tables, agent prices, commission breakdown, other expenses model, sync merge, backup round trip, form save, portfolio, summary strip, Account Ledger flows, file save logic is not unit tested).

## Not tested

- Any of this on a device or emulator in this pass (layout of the new header, summary strip, Agents section, Add Entry sheet with five options).
- A real save on Android 11 and later, Share fallback, Drive sync with the new keys.
- `desktop_shell.dart` (frozen): its rig switch does not refresh Other expenses, and it still shows the Agents screen.
