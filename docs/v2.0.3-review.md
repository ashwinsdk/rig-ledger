# RigLedger v2.0.3 review

Release 2.0.3+8. Flutter app (Android and macOS). Tasks T-K01 to T-K04 in `.claude/tasks/CURRENT.md`.

## Changes

| Item | Change |
|---|---|
| 1. Agent prices apply to old bills | `AgentsNotifier.updateAgent` runs `CommissionRecalc` when an agent is saved. Per bill: skipped if `isCommissionManuallyEdited`. Per line: a rate equal to the agent's OLD price for that line type (it came from the agent) moves to the NEW price, any other rate was typed by hand and stays. Side bore bills use the default depth rate. The bill commission is recalculated from the lines and `updatedAt` changes so sync carries it. The Edit dialog reports how many bills changed. |
| 2. Clear agent view | With an agent chosen, Portfolio Overview shows `AgentView`: agent, period, commission earned, Bills / Total / Received / Pending, a By month table (when the period spans months), then every bill with its commission and a totals row. Tapping a bill opens it. Tapping an agent in the Agents section opens this view; the info icon opens the prices sheet. |
| 3. macOS Agents screen | Removed from the sidebar, View menu, shortcuts and page stack. `agents_screen.dart` is deleted. Cmd+1 to Cmd+4 are Ledger, Portfolio, Account Ledger, Settings. |

## Decisions made without asking

- Profit stays visible with an agent chosen. Agent profit = received - commission (and expected = billed - less - commission); expenses are not tracked per agent so they are not deducted, and the agent view also shows the profit of all agents after expenses as a reference line.
- "Typed by hand" is judged by comparing the line rate with the agent's old price at save time (no new flag in the data). A rate that happens to equal the old price counts as automatic.
- New agents have no bills, so the recalculation only matters when an existing agent is edited. Adding a new rate for a type that had none (old price 0) also updates lines whose rate is 0.
- Bills of an agent on other rigs are updated too (the agent id is the key).
- The macOS freeze in CLAUDE.md was lifted for the one edit to `desktop_shell.dart`, as asked.

## Tested

124 automated tests: recalculation rules (auto, hand typed, manual total, several lines, side bore, other agents), saving through the provider, the agent view over three months with a bill outside the period and another agent's bill, back to all agents, and the earlier agent flows.

## Not tested

Anything on a device or on macOS (no `GoogleService-Info.plist`, the shell was edited without running it). Drive sync of the updated commission between two devices. Long agent names and very large amounts in the agent view at 200 percent text.
