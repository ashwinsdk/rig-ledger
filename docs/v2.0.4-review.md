# RigLedger v2.0.4 review

Release 2.0.4+9. Flutter app. Tasks T-L01 to T-L05 in `.claude/tasks/CURRENT.md`.

## Changes

| Item | Change |
|---|---|
| 1. Step rate editable per rig | New `StepTable` (start threshold, extra per ft for each 100 ft bracket, growth per further 100 ft) for the 7 inch and 8 inch tables, kept per rig in the settings key `stepRates` (backup, restore, Drive merge by newest `updatedAt` per rig, removed with the rig). Settings, Step Rates edits them with a live example, Save and Reset to standard. The built-in tables give exactly the old numbers (checked by hand). |
| 2. Agent view feet by type | `AgentView` has a Feet and commission by type card: depth, PVC and MS pipe, a chip per type with its feet and its commission subtotal (feet x the line commission rate), and a group total of feet and commission, from every line of the agent's bills in the period. A bill whose commission was set by hand counts with its line rates in this card (a note says so). |
| 3. Rig on Account Ledger entries | `CashEntry.vehicleId` (HiveField 19, optional). Entry form: Rig (optional). Income linked from a bill payment takes the bill's rig (also backfilled on existing linked income during sync). Rows show the rig, CSV has a Rig column, PDF notes get a Rig line. |

## Decisions made without asking

- "Step rate editable" is read as: edit the bracket tables per rig. There is still no per depth type table choice beyond the existing 7 inch / 8 inch table link in Ledger Types.
- "Not affecting completed entries": bills store their step rate. Opening and saving a saved bill keeps it. If you edit the depth lines of a saved bill the step rate is recalculated with the current tables (unless it was set by hand).
- Step rates apply to main bore rigs (side bore bills have no step rate).
- Entries typed by hand default to No rig. Transfers and imported entries have no rig. A linked entry's rig cannot be changed on the entry (it follows the bill).
- The rig is a label: deleting a rig leaves the id on old entries and the name is simply not shown.

## Tested
